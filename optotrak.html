OPTOTRAK MOUNT REDESIGN

Redesigned a critical mounting interface for a high-precision infrared motion capture system used in spacecraft docking tests.

ENGINEERING SUMMARY

Impact

• Eliminated shear-based failure risk in critical measurement system
• Improved alignment repeatability for docking tests
• Increased confidence in sensor data used in mission validation

Constraints

• Existing hardware interfaces could not be modified
• Required compatibility with ongoing NASA test operations
• Needed rapid fabrication and installation turnaround

Approach

1. Identified failure mode in current design
2. Modeled load path and constraints
3. Developed geometry-based solution
4. Validated through testing and iteration

SYSTEM OVERVIEW

Infrared cameras track motion during docking simulations and are mounted to a truss structure requiring high precision and rigidity.

DESIGN PROBLEM

The original mount relied on set screws in shear, creating risk of loosening and misalignment in a critical measurement system.

DESIGN CHALLENGE

Transfer loads through geometry instead of fasteners while maintaining alignment and ease of installation.

ENGINEERING SOLUTION

Introduced a twist-and-lock interface that carries structural load through geometry, with set screws only used for retention.

MECHANISM

Controlled alignment and rotation ensure repeatable installation and structural engagement.

RESULT

Improved reliability, eliminated shear-based failure risk, and increased measurement accuracy.
